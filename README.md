# ng-docserver

Standalone browser-based numerical computation tool using Monte Carlo methods. Single-file, no build step required — runs directly in any modern browser via BabelJS runtime compilation.

## ArcGIS-PCL
- Monte Carlo sampling for numerical approximation
- Real-time graphical output via HTML Canvas
- Zero dependencies — all libs loaded from CDN
- ES6 class component architecture

## BitchX1-4-2023
No installation needed. Open `index.html` in a browser.

CDN libraries used:
- https://babeljs.io/docs/babel-standalone
- https://cdnjs.com/libraries/react
- https://cdnjs.com/libraries/react-dom
